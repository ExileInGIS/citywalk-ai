# CityWalk AI 用户流程（User Flows）

> 版本：v1.0 · 2026-10-26
> 对应 PRD：`docs/PRODUCT-REQUIREMENTS.md` v1.0
> 所有流程均以「Mock 模式可完整走通、Remote 模式按同一契约替换」为前提。

---

## 0. 角色与入口

| 角色 | 入口 | 状态 |
| --- | --- | --- |
| 首次访客 | 首页工作台 | 无收藏、无历史 |
| 回访用户 | 首页 / 我的收藏（localStorage） | 恢复收藏路线与条件 |
| 发现型用户 | 发现路线 → 查看/使用精选路线 | 以精选路线为起点再规划 |
| 服务异常时的用户 | 任意页面 | 看到降级/错误/重试入口 |

## 1. 首次规划（Happy Path）

```
[首页]
 用户输入一句话 / 点选兴趣 / 展开高级筛选
   ↓
[前端] 清洗输入 → 本地解析预览 → 组装 Conditions
   ↓
[点击「生成我的 CityWalk 路线」]
   ↓
[加载态] 4 个阶段：理解偏好 → 筛选地点 → 组织顺序 → 检查约束
   ↓
[服务端 workflow]
 意图=plan → 结构化 → 必填检查（通过）→ 检索 → 过滤 → 排序 → 计算 → 校验
   ↓
[结果页]
 摘要（时长/地点数/距离/预算）＋ 地图 ＋ 时间线 ＋ 约束清单 ＋ 理由 ＋ 来源/估算提示
   ↓
[用户操作] 收藏 / 调整 / 手动排序 / 分享 / 导出
```

**关键状态**

| 状态 | UI | 可执行操作 |
| --- | --- | --- |
| idle | 精选路线 + 地点发现 | 输入、生成 |
| loading | 阶段进度，禁用重复提交 | 取消（可选）、修改条件（不提交） |
| result | 结果区 | 调整、收藏、排序、导出、重新规划 |
| error | 错误说明 + 重试 | 重试、返回修改条件 |

**空/边界**

- 未选任何兴趣：按自然语言与默认偏好规划，条件卡显示「未指定（按均衡偏好）」；
- 未填预算：正常生成，预算显示「未指定」，不替用户设上限；
- 时长 < 60 分钟：提示「时间较短，可能只安排 1–2 站」，允许继续或修改。

## 2. 信息不全（Clarification）

```
用户：「帮我规划一条 CityWalk 路线」
   ↓
[服务端] 必填检查：city 缺失、duration 缺失
   ↓
[返回] clarification: { questions:[
   { id:'city', text:'你想在哪座城市漫步？', options:['南京','苏州','杭州'] },
   { id:'duration', text:'大概有多少时间？', options:['2 小时','3 小时','4 小时','半天'] }
]}
   ↓
[前端] 在对话区/澄清卡展示问题（最多 3 个，可跳过非关键项）
   ↓
用户点选「南京」「3 小时」
   ↓
[前端] 合并条件 → 重新请求 plan
   ↓
生成结果（或继续追问缺失的必去点等）
```

**规则**

- 缺城市或时长：**不生成**，不猜；
- 其他字段缺失：使用默认值并在条件卡标注「未指定/默认」；
- 追问最多 3 个；用户跳过则按默认继续，结果页标注「未指定项」；
- 追问期间不丢失已输入文本与已选标签。

## 3. 硬约束冲突（Conflict）

### 3.1 时间不足

```
用户：必去 A/B/C，总时长 2 小时
   ↓
[服务端] 计算最短可行时长 3 小时 20 分 → 硬约束 violated
   ↓
[返回] route（尽力安排）＋ conflict:
  { type:'time', title:'时间预算不足',
    detail:'按你的必去点与停留时间，至少需要 3 小时 20 分，超出 80 分钟。',
    options:[
      { id:'extend_time', label:'把时长放宽到 3.5 小时' },
      { id:'drop_last',   label:'去掉一个必去点' },
      { id:'shorten_stay',label:'每站停留缩短 15 分钟' }
    ] }
   ↓
[前端] 冲突卡片（醒目但阻断性弱）＋ 地图/时间线仍可查看
   ↓
用户点选选项 → 服务端按选项重算 → 再次校验 → 更新结果 + 说明
```

### 3.2 预算不足

- 优先替换为免费/低价地点；仍超 → conflict `budget`，选项：提高预算 / 去掉高消费点 / 保留但标注超支；
- 任何选项执行后必须重新计算并展示新的预算区间。

### 3.3 必去点无法满足

- 地点不存在 → conflict `must_visit_missing`，给「去掉该点 / 换成相似地点」；
- 必去点与时间冲突 → 同 3.1；
- **不得静默删除必去点**。

### 3.4 步行超限 / 无障碍

- 步行超限 → 选项：减少一站 / 放慢节奏 / 接受超出（明确标注）；
- 无障碍：无数据的点位标 `unknown`，**不声称可无障碍通行**；提供「只保留有已知无障碍信息的点」选项（若数据不足则明确说明无法满足）。

## 4. 自然语言调整（Refine）

```
用户输入调整指令
   ↓
[前端] 串行队列（避免连续指令互相覆盖）→ POST /api/agent/run(refine)
   ↓
[服务端]
 1. 意图识别（少走路 / 换地点 / 加主题 / 预算 / 时间 / 保留首尾 / 天气 / 去重）
 2. 定位受影响段
 3. 局部修改（保留未受影响部分）
 4. 重算时间/预算/距离
 5. 重新校验硬约束
   ↓
[返回] { changed, reply, bullets[], changes[], constraintsAfter[], unresolved[], route, conflict? }
   ↓
[前端] AI 气泡（回复+要点）＋ 差异条（前→后）＋ 更新地图/时间线/摘要
```

### 4.1 指令与预期行为

| 指令示例 | 行为 | 必须展示 |
| --- | --- | --- |
| 「少走一点路」 | 移除绕路最大的一站或就近重排 | 新距离/时长、移除了哪站 |
| 「把咖啡馆换成书店」 | 同类替换，保持位置 | 替换前后、影响的时间 |
| 「我想多看一些历史建筑」 | 增加历史类地点或替换低相关点 | 新增点、理由、时长变化 |
| 「预算控制在 100 元以内」 | 去掉/替换高消费点 | 新预算区间、是否仍超 |
| 「下午五点前结束」 | 压缩停留或减少站点 | 新结束时间、是否冲突 |
| 「保留第一站和最后一站，调整中间」 | 首尾锁定，中间重排 | 锁定说明、中间变化 |
| 「下雨了，尽量安排室内活动」 | 室内点优先替换露天点 | 哪些点因室内信息未知无法保证 |
| 「不要再安排类似的景点」 | 多样性约束，替换同类 | 去重后的类别分布 |

### 4.2 不可执行/歧义指令

- 无法识别 → 回复「我没理解这条调整」+ 示例指令，不修改路线；
- 指令与硬约束冲突 → 不静默执行，返回 `conflict` 与选项；
- 多轮指令后：仍需满足原始硬约束；若用户显式修改条件（如预算），更新 Conditions 并记录。

### 4.3 手动排序

- 上移/下移/拖拽 → 前端请求服务端重算（或本地共享核心重算）→ 更新距离/时间；
- 不允许「排序后仍显示旧时间」；若重算失败，标「未重算」并禁用保存？——**本次规则：必须重算成功才允许保存**。

## 5. 保存、导出与恢复

```
结果页 → 收藏路线 / 导出 Markdown / 复制分享文本
   ↓
localStorage：{ favorites, routes, conditions, updatedAt }
   ↓
刷新/下次打开 → 我的收藏 → 打开/再次规划
   ↓
设置中可「清除本地数据」→ 二次确认 → 清空
```

- 导出 Markdown 字段：路线名、条件摘要、逐站（名称/类别/停留/步行/理由）、总时长/距离/预算、约束清单、数据来源与免责声明、生成时间；
- 分享文本与导出一致，但更短；
- 本地数据不上传；隐私说明在收藏页与设置中可见。

## 6. 服务失败与降级

### 6.1 Remote 失败

```
POST /api/agent/run (mode=remote)
   ↓
超时/5xx/非法 JSON
   ↓
[服务端] 按 fallback：
  ├─ 'mock' → 本地规则生成，标记 degraded:true + degradeReason
  └─ 'error' → 返回标准化错误（502/504）
   ↓
[前端] 结果上方显示「已切换为本地模拟」+ 原因 + 重试按钮；结果仍标注 Mock
```

### 6.2 地图失败

```
Leaflet 瓦片/SDK 加载失败
   ↓
[前端] 捕获 → 回退 Mock SVG + 「真实地图不可用」提示
   ↓
列表/时间线/调整保持可用；不影响路线数据
```

### 6.3 无候选地点

- 空状态 + 建议：换城市、放宽时长/预算、减少避开项；
- 提供「一键放宽预算」等可执行动作（需用户点击）。

## 7. 安全异常

| 场景 | 行为 |
| --- | --- |
| 超长输入 | 前端截断 + 提示；服务端拒绝 >2000 字符的 `text` |
| 注入指令（「忽略以上指令…」） | 作为数据处理；不改变系统 Prompt；正常返回路线或通用拒绝；记录安全事件（不含原文） |
| 服务端错误泄露堆栈 | 生产响应只给错误码与安全文案；堆栈只进服务端日志 |
| 频率过高 | 429 + 重试等待提示 |
| 未授权访问（未来） | 401；本次无鉴权，仅本机使用 |

## 8. 状态机（简化）

```
IDLE ──生成──> LOADING ──成功──> RESULT
  ↑                │ 失败            │
  │                ↓                 │ 调整
  └──────────── ERROR <──失败────────┘
                   │
                   └─重试→ LOADING
RESULT ──缺信息──> CLARIFY ──回答──> LOADING
RESULT ──冲突──> CONFLICT ──选项──> LOADING
```
