## IP-001：四步生成进度

- **触发条件**：用户在首页点「生成我的 CityWalk 路线」，且规划需要数秒。
- **流程描述**：
  1. 用户操作：点主按钮。
  2. 系统响应：左栏按钮文案变为「正在为你规划…」并禁用；右栏整块切换为加载态（转圈 + 标题「正在为你规划路线」）。
  3. 系统响应：四个步骤依次从待办变为进行中（深色文字 + 转圈图标），完成后变实心对勾，每步约 420–640ms。
  4. 系统响应：四步走完后加载态整体替换为结果（摘要卡 → 地图 → 时间线），并 toast「路线已生成」。
- **状态说明**：
  - 待办：`--ink-4` 文字 + 空心圆；
  - 进行中：`--ink` 文字加粗 + 圆环旋转；
  - 完成：`--ink-2` 文字 + `--forest` 实心对勾。
- **异常处理**：规划抛错时**不留在加载态**，回到上次结果或空态，并在对话里插入「规划服务暂时不可用」+ 重试指引。
- **适用场景**：所有耗时超过 1 秒的 AI 生成动作（路线规划、批量调整）。
- **引用案例**：`js/pages/home.js` 第 344–422 行（生成流程）、第 424–433 行（步骤绘制）、`css/style.css` 第 495–508 行（加载态样式）。

## IP-002：对话式调整 + 前后对比

- **触发条件**：路线已生成，用户想改而不是重新填表。
- **流程描述**：
  1. 用户操作：在 AI 面板输入一句话，或点一个快捷指令胶囊（如「缩短步行距离」）。
  2. 系统响应：多条指令**串行排队**执行，避免连点互相覆盖；用户消息立刻上屏。
  3. 系统响应：AI 气泡给出结论 + 要点列表；能定量对比的变更以「原值（划线）→ 新值（绿色加粗）」呈现。
  4. 系统响应：摘要卡、地图、时间线**局部刷新**，保持地图缩放状态；toast「路线已更新」。
- **状态说明**：无 response 中的 loading 指示（依赖串行队列）；成功＝出现对比块；未识别＝回复里说明原因，不假装改动。
- **异常处理**：调整失败时气泡显示「调整失败」并给手动入口；远程降级时追加「已切换为本地模拟」。
- **适用场景**：生成后的所有修改（缩短步行 / 增删某类地点 / 改时长 / 改预算 / 调节奏 / 复合指令）。
- **引用案例**：`js/pages/home.js` 第 435–461 行（发送与串行化）、第 195–212 行（气泡与对比块渲染）、第 478–483 行（`.diff-box` 样式）。

## IP-003：约束冲突 → 选项 → 收敛

- **触发条件**：生成或调整后，路线与时间/预算约束冲突。
- **流程描述**：
  1. 系统响应：摘要卡出现琥珀色提示条，写清冲突标题与量级（「当前安排约需 4 小时 40 分，超出你给的 3 小时」）。
  2. 系统响应：对话气泡附带琥珀色选项胶囊（「减少一个地点」「调整为轻松节奏」）。
  3. 用户操作：点其中一个选项。
  4. 系统响应：按选择重排路线并回复结果；若仍冲突，再次给出新选项，直到收敛。
- **状态说明**：冲突中＝琥珀提示条 + 选项胶囊；已解决＝提示条消失；换成新冲突＝提示条内容替换。
- **异常处理**：所有选项都不可行时，保留当前安排并说明「就这样出发」之类的兜底选项，不强行改路线。
- **适用场景**：时间预算、消费预算、必须到达时间、体力约束。
- **引用案例**：`js/pages/home.js` 第 292–303 行、第 585–588 行；`js/agent.js` 第 529–561 行、第 565–590 行。

## IP-004：未生成时「占位即内容」

- **触发条件**：首页加载完成但用户尚未生成路线。
- **流程描述**：
  1. 系统响应：右栏不显示空白骨架屏，而是「先看看别人怎么逛」的精选路线 + 6 张地点发现卡。
  2. 用户操作：点「一键体验」直接载入精选路线并进入结果态；或点某个地点卡打开详情、顺手收藏。
  3. 系统响应：载入后在对话里说明「地点顺序为预设内容，时长与距离为估算值」。
- **状态说明**：空态＝有内容可看、有下一步可点；不使用灰色占位块。
- **异常处理**：精选路线不存在时退回地点发现网格（静态数据，实际不会为空）。
- **适用场景**：首屏、任何「还没开始用」的空态。
- **引用案例**：`js/pages/home.js` 第 485–536 行。

## IP-005：地图 ↔ 列表双向联动

- **触发条件**：结果页同时显示地图与时间线。
- **流程描述**：
  1. 用户操作：点地图上的编号标记。
  2. 系统响应：对应卡片加选中边框并滚动到视野中间。
  3. 用户操作：点某张地点卡。
  4. 系统响应：地图标记放大高亮，并轻微平移聚焦；再点同一项取消选中。
- **状态说明**：选中＝卡片 `.sel` 边框 + 地图白底放大标记；未选中＝常规态。手动调整顺序后，两侧编号同步重画。
- **异常处理**：手动排序后距离与时间**不重算**，界面明确提示「顺序已更新，距离与时间未重新计算」。
- **适用场景**：路线结果页、任何地图 + 列表并存且需要对应的界面。
- **引用案例**：`js/pages/home.js` 第 662–673 行（点击委托）、第 767–785 行（选中联动）、`js/map.js` 第 236–248 行（选中聚焦）；手动排序后「不重算」的如实提示在 `home.js` 第 744–757 行。

## IP-006：空状态带出口

- **触发条件**：筛选无结果、没有收藏。
- **流程描述**：
  1. 系统响应：说明「为什么是空的」，并给出可执行出口按钮（「重置筛选」「去规划一条路线」「浏览发现路线」）。
  2. 用户操作：点出口按钮。
  3. 系统响应：直接离开空态（重置筛选 / 跳首页 / 跳发现路线）。
- **状态说明**：空态＝圆形图标 + 一句话标题 + 一句解释 + 1–2 个按钮，不留死胡同。
- **异常处理**：收藏因会话重置而失效时，用琥珀提示条说明「有 N 条收藏来自已重置的会话数据，无法还原」。
- **适用场景**：筛选结果、收藏列表、搜索无结果。
- **引用案例**：`js/pages/discover.js` 第 100–107 行；`js/pages/favorites.js` 第 37–53 行、第 69–76 行、第 42–43 行。
